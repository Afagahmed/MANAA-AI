# مناعة | MANA'A — نموذج أولي

واجهة عربية تجريبية لمنصة تواصل مخصصة للاستخدام داخل دولة الإمارات، مع عرض حالة الموقع لجميع المستخدمين.

## تشغيل النموذج
افتح `index.html` في أي متصفح حديث. لا يحتاج إلى تثبيت أو خادم.

## ما الذي يمكن عرضه؟
- شاشة تسجيل تجريبية باسم UAE PASS (غير متصلة بالخدمة).
- إدخال رقم هاتف تجريبي.
- محاكاة حالات: داخل الإمارات (أخضر)، خارج الإمارات (أحمر)، غير متحقق (رمادي).
- قائمة جهات اتصال تظهر حالاتهم لجميع المستخدمين.
- محادثة نصية محلية تجريبية داخل الصفحة.

## حدود مهمة
هذا نموذج واجهة أمامية فقط. لا يوجد تسجيل دخول حقيقي، ولا تحقق فعلي من UAE PASS أو رقم الهاتف، ولا إرسال رسائل عبر الإنترنت، ولا تحديد فعلي للموقع أو تحقق موثوق من حدود الدولة. الأسماء والحالات المعروضة أمثلة توضيحية.

لتحويله إلى منتج حقيقي، يلزم:
1. موافقات وتكامل رسمي مع UAE PASS وفق متطلبات الجهة المشغلة.
2. تحقق آمن من رقم الهاتف.
3. خدمة خلفية وقاعدة بيانات ومراسلة آمنة.
4. آلية موقع بموافقة المستخدم، وتحديد صلاحية الحالة ووقت آخر تحقق، وحماية البيانات وتقليل جمع الموقع.
5. مراجعة قانونية وأمنية وخصوصية قبل الإطلاق.

## وصف الفكرة
منصة تواصل تسعى إلى تعزيز الثقة الرقمية عبر التحقق من الهوية وعرض حالة جغرافية مبسطة للمستخدمين. الأخضر يعني أن آخر تحقق يشير إلى وجود المستخدم داخل الإمارات، والأحمر يعني أن آخر تحقق يشير إلى وجوده خارجها، والرمادي يعني عدم توفر تحقق. اللون لا يدل على أن الشخص موثوق أو محتال.
